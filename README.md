# Smart Expense Tracker

Smart Expense Tracker is a full-stack expense management application that helps users manage income and expenses, track transactions, filter data, and view monthly financial summaries.

## Features

- Add income and expense transactions
- Edit existing transactions
- Delete transactions with confirmation
- Transaction categories
- Transaction date management
- Search transactions
- Filter by Income / Expense
- Monthly transaction filtering
- Monthly income, expense, and balance summary
- Expense category Pie Chart
- Date-based transaction sorting
- Form validation
- Success messages
- Indian currency formatting
- Data stored in MySQL
- REST API using Spring Boot
